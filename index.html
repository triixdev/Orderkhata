Orderkhata / WhatsApp order sorter for small shops / version 0.2

Orderkhata

Paste a WhatsApp chat where customers order in Bengali, Hindi, English or a mix. Get one line per customer with items, quantities, the time they asked for and a total from your own price list. Rentals are priced by the day. Every line is either checked or quoted. If a message is unclear it is flagged for you and never guessed.

How a message is checked

  1. The chat is split into messages by sender. Lines that continue a message are joined to it.
  2. Bengali and Devanagari digits become ordinary digits. Number words such as ek, dui, তিন, चार and দুটো are read as numbers.
  3. Item names are compared with your price list after spelling swaps (sh and s, o and a, doubled letters) are ignored. An exact match is accepted. A one letter miss is accepted but flagged so you confirm the spelling.
  4. A quantity is taken only from a number right next to the item. If none is there the line shows a question mark and a flag.
  5. An item priced per day is a rental. It needs a rental word such as rent or hire in the message and a number of days. A month counts as 30 days and a week as 7.
  6. Kilograms against a per piece price, dozens, very large quantities, cancellation words, correction words and the same item in two messages are all flagged.
  7. The words for day and time (kal, আজ, शाम, 7 बजे) are shown exactly as written without translation.

What this page does not do

This page uses fixed rules and short word lists. It misses sentences the rules do not cover and flags them for you. A browser page cannot download or run an open-weight model under the privacy settings used here, so no model runs on this page.

The model version

The Python script in the repository runs Gemma on your own computer through Ollama. Gemma reads each message and answers with items, quantities and the exact words it relied on. Code then checks every answer against the message and your price list, allows one retry, and otherwise hands the message back untouched. Prices and totals always come from your list. Install Ollama, pull the model, then run these two commands in the repository folder.

ollama pull gemma3:4b
python gemmascript.py sort chat.txt --model gemma3:4b

The evaluation numbers are in the DEV post. They come from running the same 25 messages through three prompt versions with python gemmascript.py eval.

Privacy policy

Last updated 19 October 2026.

What this page does with your data

The chat and price list you paste are processed in your browser’s memory and are not sent anywhere. The page has no analytics, trackers, cookies, advertising code or third party fonts and scripts.

Enforced by the browser

The page declares a Content Security Policy that blocks every outgoing request from its code and forbids form submission. A mistake in the page could not post your chat to a server. You can check this in your browser’s developer tools.

Other people’s details

Chats contain customers’ names, phone numbers and addresses. Use only chats you are allowed to use. Equipment orders can show that someone is unwell so remove names and addresses before pasting. The Erase button clears everything at once.

What is kept

Nothing. No local storage, session storage, IndexedDB or cookies are used. Reloading the tab discards your text. The CSV is only text in the box above. Copy it yourself.

The host

The hosting provider may log ordinary request details, such as your IP address, when you load the page. Those logs cover loading the page only.
